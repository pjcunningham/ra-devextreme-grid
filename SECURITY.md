# Security Policy

## Supported Versions

Only the latest release candidate and stable releases of `ra-devextreme-grid` receive security updates.

| Version | Supported          |
| :------ | :----------------- |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

---

## Reporting a Vulnerability

We take the security of `ra-devextreme-grid` seriously.

If you believe you have found a security vulnerability in this project, please report it responsibly rather than opening a public issue.

### Preferred Method: GitHub Security Advisories

Please report vulnerabilities privately via GitHub:

1. Navigate to the repository's **Security** tab on GitHub: [https://github.com/pjcunningham/ra-devextreme-grid/security](https://github.com/pjcunningham/ra-devextreme-grid/security).
2. Click **Advisories** and select **Report a vulnerability**.
3. Provide details including:
   - Component affected (`DatagridDX`, `DatagridDXRemote`, filter parser, etc.).
   - Description of the potential impact.
   - Step-by-step instructions or minimal proof-of-concept reproducing the issue.

### What to Expect

- A maintainer will acknowledge receipt of your report within 48 hours.
- We will investigate and validate the vulnerability.
- A fix will be developed and released in an upcoming patch release.
- You will receive credit in the changelog and release notes unless you prefer to remain anonymous.

Thank you for helping keep this project safe and reliable.
